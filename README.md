# WALMART-STORE-SALES-P-ANALYSIS

**Project Description**

This project analyses weekly sales performance across 45 Walmart stores to identify the factors influencing revenue generation and store performance. Using Excel, SQL, and Power BI, the analysis evaluates the impact of holiday periods, temperature, fuel prices, and unemployment rates on sales, identifies top and bottom-performing stores, and examines sales trends over time.

The project combines correlation analysis, ranking techniques, window functions, and interactive dashboards to generate business insights, including the impact of holidays on consumer spending and month-over-month sales growth. The findings support data-driven decision-making for inventory planning, promotional strategies, and store performance management.
